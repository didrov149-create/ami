# Кино на двоих

Совместный просмотр фильма: один открывает файл у себя, второй смотрит по ссылке. Пауза, перемотка и чат работают у обоих.

Сайт: https://didrov149-create.github.io/ami/

## Как устроено

- Фильм никуда не загружается. Браузер ведущего передаёт картинку и звук второму напрямую (WebRTC).
- Чтобы браузеры нашли друг друга, используются публичные MQTT-ретрансляторы. Сообщения шифруются ключом из ссылки, видео через них не идёт.
- Если ретрансляторы недоступны, можно соединиться через код: ведущий отправляет ссылку, второй присылает ответный код.
- Весь сайт — один файл `index.html` и шрифты, сборка не нужна.
- Шрифты Sofia Sans и Sofia Sans Extra Condensed (Lettersoup), лицензия SIL Open Font License 1.1.
